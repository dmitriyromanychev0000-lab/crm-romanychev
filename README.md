# CRM by Romanychev

Восстановленная local-first CRM мастера по ремонту техники.

## Что уже работает

- импорт бэкапов формата CRM BT v18;
- локальное хранение данных в IndexedDB;
- заявки, склад, аналитика и прайс;
- ручной экспорт JSON;
- выбор папки и автоматические бэкапы с интервалом 1, 2, 3, 5, 7 или 14 дней;
- установка как PWA и офлайн-кэш.

## Безопасность

Данные клиентов остаются в браузере. Исходные JSON-бэкапы, `.env`, фотографии и персональные данные не должны попадать в Git.

## Запуск

Откройте проект через любой статический HTTP-сервер, например:

```bash
npx serve .
```

Для выбора папки браузеру нужен безопасный контекст (`https` или `localhost`) и поддержка File System Access API. На неподдерживаемых устройствах используется обычное скачивание файла.
