# CRM by Romanychev

Local-first CRM мастера по ремонту техники. Текущая версия приложения: **0.22.0**.

## Открыть приложение

Постоянный адрес GitHub Pages:

https://dmitriyromanychev0000-lab.github.io/crm-romanychev/

Адрес не меняется между версиями. Номер установленной сборки виден в разделе **Ещё → Настройки**.

## Что работает

- заявки: создание, редактирование, копирование, статусы, архив и восстановление;
- услуги, материалы, фотографии и черновики заявок;
- склад: приход, списание, автосписание из заявок, возвраты и критические остатки;
- прайс-лист и пользовательские услуги;
- клиенты и история обращений;
- финансы с фильтрами по периоду;
- аналитика ремонтов, личных финансов, техники и расхода материалов;
- товарник с целевой суммой и подгонкой цен;
- инструменты;
- документы/чеки и акты выполненных работ;
- настройки мастера и реквизитов;
- сохранение текущего раздела и позиции после перезагрузки;
- PWA и офлайн-кэш.

## Бэкапы и защита данных

Данные хранятся локально в браузере через IndexedDB.

В разделе **Ещё → Бэкапы** доступны:

- импорт CRM BT v18;
- скачивание JSON-бэкапа;
- сохранение в выбранную папку;
- автоматический бэкап;
- встроенная проверка бэкапа;
- точка отката перед импортом;
- отмена последнего импорта.

Перед крупными изменениями рекомендуется сделать отдельный JSON-бэкап.

## Обновление приложения

Обычно достаточно открыть постоянную ссылку. CRM проверяет обновление service worker без HTTP-кэша.

Если версия не изменилась, откройте **Ещё → Настройки → Проверить обновление**. После установки новой сборки приложение возвращается на постоянный адрес.

## Локальный запуск

Проект полностью статический. Для локального запуска можно использовать любой HTTP-сервер, например:

```bash
npx serve .
```

Для выбора папки браузеру нужен безопасный контекст (`https` или `localhost`) и поддержка File System Access API. На неподдерживаемых устройствах используется обычное скачивание JSON.

## Безопасность

Персональные данные клиентов и фотографии не должны коммититься в Git. Рабочая база находится в браузере пользователя, а не в репозитории.
