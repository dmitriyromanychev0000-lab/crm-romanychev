# UI / UX audit — 2026-09-26

Текущая цель: довести мобильную CRM до approved-направления из `Visual_koncept/`, сохранив всю рабочую функциональность.

## Главный системный вывод

`styles.css` накопил десятки исторических визуальных слоёв. Перед началом 0.85.0 в файле было около 366k символов, 35 mobile media-блоков для 520 px, 60 версионных CSS-секций и более 700 `!important`. Из-за этого точечные изменения дают слабый визуальный эффект и часто перекрываются старым CSS.

0.85.0 начинает канонический финальный слой вместо дальнейшей микрополировки отдельных правил. После стабилизации экранов старые дублирующиеся слои нужно будет удалить отдельным cleanup-проходом.

## Сквозные проблемы

1. Старые CSS overrides — главный технический долг.
2. Слишком мелкая типографика 7–9 px на части вторичных экранов — в 0.85.0 начато исправление.
3. Native browser confirm визуально выбивались из CRM — в 0.85.0 все 9 заменены фирменным диалогом.
4. Touch-targets ниже 44 px встречались в служебных экранах — в 0.85.0 увеличены основные проблемные кнопки.
5. Требуется финальная проверка ширин 360 / 390 / 430 px.
6. После визуального завершения нужен cleanup старых CSS-блоков, чтобы новые изменения больше не «терялись».
