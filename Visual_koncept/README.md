## Rules for Work

- These images define **layout, hierarchy, density, spacing, colour direction, control proportions and interaction placement**.
- Current CRM code defines **behaviour, data model, migrations and functional compatibility**.
- If AI-generated text inside a mockup is distorted, use the current CRM labels/data as the textual source of truth.
- Do not remove working functionality just because it is not visible in one concept image.
- Optimise primarily for phone widths around 360–430 px.
- Validate each implemented screen against its corresponding concept image before moving to the next sheet.
